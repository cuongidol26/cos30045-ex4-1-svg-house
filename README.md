# Exercise 4.1 SVG house

A house and garden drawn with SVG shapes (rect, circle, ellipse, line, polyline, polygon, path, text). The two windows are grouped in a `<g>` and positioned with `transform="translate(...)"`.

- `index.html`: the SVG and explanations
- `images/house-annotated.png`: coordinates of each shape type
- `images/dom-screenshot.png`: the SVG in browser developer tools

GenAI use: see the separate GenAI declaration submitted on Canvas.
